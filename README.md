# Sana Mushtaq - Personal Portfolio & Alshifa Hospital Management Record

A premium, modern, and futuristic personal portfolio website for Sana Mushtaq, a Computer Engineering Student and Web Developer.

## Features

- **Futuristic UI/UX:** Deep navy, electric cyan, and subtle purple aesthetics with glassmorphism effects.
- **Pure Technologies:** Built entirely using HTML5, CSS3, and Vanilla JavaScript (No frameworks like React, Tailwind, etc.).
- **Interactive Background:** Features a subtle, interactive particle background using tsParticles.
- **Custom Cursor:** Includes a smooth, magnetic custom cursor for desktop users.
- **Responsive Design:** Fully responsive layout that adapts to desktop, tablet, and mobile devices perfectly.
- **Scroll Animations:** Uses `IntersectionObserver` for smooth, performant scroll-reveal animations.
- **Performance Optimized:** Includes respect for `prefers-reduced-motion` and dynamic particle density based on screen size.

## File Structure

```
portfolio/

├── style.css         # CSS styles and animations
├── script.js         # Vanilla JavaScript functionality
│
├── assets/
│   └── profile.png   # Professional portrait image
│
└── README.md         # Project documentation
```

## Setup & Usage

To view the website:
1. Clone or download this repository.
2. Ensure the `assets/` directory contains your `profile.png` image.
3. Simply double-click `index.html` to open it in any modern web browser. No local server is strictly required, though it is recommended for best performance and to ensure all assets load correctly.

## Technologies Used

- **HTML5:** Semantic markup.
- **CSS3:** Custom properties (variables), Grid, Flexbox, Keyframe Animations, Glassmorphism techniques.
- **JavaScript (ES6+):** DOM manipulation, IntersectionObserver, requestAnimationFrame.
- **tsParticles (via CDN):** For the interactive particle background effect.
- **FontAwesome (via CDN):** For icons used throughout the site.
- **Google Fonts:** Using 'Outfit' font family.
